# APUASC-GroupAT
Repository for working OODJ Group AT APU-ASC program; name of program: Auttomov Software

# GitHub Practices and Guideline
**Branch structure**
1. seanwzs/jayvee/ziyang/songhan - your own branch, think as your workspace to upload your code
2. frontend/backend - merge with your partner's code as whole
3. test - when frontend and backend are complete, we push it to test branch to test our code, before main branch
4. main - the primary branch for our complete code

**Branch flow**
- Commit and push to branch left to right
- Own branch -> frontend/backend -> test -> main (master)
- E.g. seanwzs -> frontend/backend -> test -> main (master)
- Please **DO NOT** push from any branches to the main branch.

**Pull request**
- PR is optional when pushing from own branch to frontend/backend; discuss with your teammate
- Must raise PR from frontend/backend branch to test branch for confirmation

*Note*
- Always give a clear and concise commit message, communicating with your team well
- **Always pull before pushing**, which means update project from remote to your local repo first, before pushing code to remote
- If there are merge conflicts, please resolve them immediately
