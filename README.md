# APUASC-GroupAT
Repository for working OODJ Group AT APU-ASC program; name of program: Auttomov Software

**Branch structure**
- Commit and push to branch left to right
- Own branch -> frontend/backend -> main (master)
- E.g. seanwzs -> frontend/backend -> main (master)

**Pull request**
- PR is optional when pushing from own branch to frontend/backend; discuss with your teammate

*Note*
- Please **DO NOT** push from frontend/backend branch to main branch. We will do it when integrating our system as whole.
